# Что умеет Fusion и чего НЕТ (сверено с кодом платформы 06.11.2026)

Обещай клиенту только из раздела «Есть». Всё из раздела «Нет» говори честно: «этого пока нет» или «проверю у команды Fusion».

## Есть

**Каналы**
- WhatsApp: по QR-коду (обычный номер) и WhatsApp Cloud API (официальный, с шаблонами сообщений).
- Instagram: ответы в директ и на комментарии. Правила «когда отвечать»: на комментарий или на директ; слово целиком, слово внутри фразы или «на всё»; выбор постов; статистика по правилу и слову.
- Telegram: бот клиента.
- Виджет на сайт (на платных тарифах).
- Голосовые сообщения клиента агент слушает сам (платформа расшифровывает). Фото видит, если у агента включён переключатель «обработка изображений» (команда `agents set --image on`).

**Агент**
- Сколько угодно агентов на аккаунте, агента можно клонировать (`agents clone`).
- База знаний: PDF, Word, Excel, текстовые файлы, ссылки на сайты, Google Диск. Агент ищет в базе сам, поиск возвращает несколько фрагментов.
- Файлы и фото для отправки: медиатека, наборы (до 10 файлов в наборе), фото-каталог. Агент находит и отправляет сам. В одном ответе уходит одно вложение, поэтому несколько фото отправляют набором.
- Заполнение с нуля: анкета и ИИ-интервью, промпт по сайту или Instagram (черновик, дальше доводим по методологии).
- Переключение «агент / менеджер»: когда менеджер пишет сам, ИИ можно отключать (настройка агента).
- Часовой пояс агента: платформа сама знает дату, время и день недели. Писать их в промпт не надо.

**Работа с заявками**
- Поля заявки (карточка) и передача менеджеру в Telegram-группу через @FusionNotify_Bot.
- «Мои клиенты»: список людей, метки, выгрузка в Excel, лента событий.
- Дожимки: напоминания молчащим, до 5 шагов, в 4 каналах, только в безопасные часы (см. `dozhimki.md`).
- Аналитика: сообщения, диалоги, каналы, квалифицированные лиды.

**Интеграции**
- amoCRM (шесть инструментов агента, подробнее в `crm-kalendar.md`) и Bitrix24 (тариф «Бизнес»).
- Google Календарь (с 29.10.2026) и Altegio: только по подтверждению команды Fusion, см. правило про запись на время.
- Промокоды и реферальная программа платформы, приложение для телефона (PWA).

## Нет (план или ТЗ)

- Общий входящий ящик команды с распределением диалогов и ролями.
- Массовые рассылки по базе.
- CSAT и SLA-отчёты.
- Приём оплаты в чате. Оплата FinikPay и FreedomPay относится к оплате подписки Fusion, а не к оплате покупок клиента вашего клиента.
- Google Таблицы как интеграция, MCP для клиентов.
- Почта, SMS, голосовые звонки, Facebook Messenger.
- 1С и МойСклад (только по индивидуальному договору на тарифе Enterprise).
- Агент не видит, какие окошки заняты: сам по себе записать на свободное время он не может.
- У агента нет таймера: «напомню через 10 минут» невозможно. Напоминания молчащим делают дожимки.
- Платформа не передаёт агенту, с какой именно рекламы пришёл человек.

## Как агент устроен внутри (нужно для промптов)

- Инструменты агента (имена писать только такие): `find_context_from_knowledge_base`, `escalate_to_manager`, `upsert_user_attribute`, `send_user_information_to_manager`, `crm_get_context`, `crm_ensure_lead`, `crm_move_lead_stage`, `crm_add_note`, `crm_assign_responsible`, `crm_create_task`, `find_sendable_assets`, `emit_sendable_asset_response`.
- Инструмент срабатывает, только если его способность описана в промпте. Молчание промпта равно отказу клиенту.
- Передача заявки (`send_user_information_to_manager`) и поля профиля (`upsert_user_attribute`) появляются у агента только при заполненных полях заявки и подключённых уведомлениях. Без этого инструмента нет.
- Реальную модель выбирает платформа (цепочка моделей), в кабинете поле модели формальное. Названия моделей в промпт не писать.
- Температура для консультанта 0–0,3 (`agents set --temperature 0.2`).
- Один перевод строки в ответе делит его на отдельные сообщения, пустая строка склеивает.
