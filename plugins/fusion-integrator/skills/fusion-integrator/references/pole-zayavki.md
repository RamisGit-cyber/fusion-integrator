# Поля заявки и передача менеджеру

## Главная ловушка

Если у агента нет полей заявки (шаблон профиля пустой), платформа не выдаёт ему инструмент `send_user_information_to_manager`. Агент отвечает «не могу передать менеджеру», и заявка не уходит никому. Это проверено на живых агентах. Проверяй у КАЖДОГО нового агента: `fields show --agent ID`.

Исправление: `fields set --agent ID` (набор по умолчанию: Телефон — обязательный, Имя клиента, Интерес, Вопрос менеджеру) или свой набор через `--file поля.json`:

```json
[
  {"label": "Телефон", "required": true, "description": "Номер телефона клиента для связи менеджера.", "examples": ["0555 123 456"]},
  {"label": "Имя клиента", "required": false, "description": "Как зовут клиента.", "examples": ["Азамат"]}
]
```

Скрипт не даст сохранить набор без обязательного «Телефон». Поле «Название» до 50 знаков, описание до 300, примеров не больше 5.

## Как платформа ведёт заявку

- Платформа вшивает в агента правило: «вызови `send_user_information_to_manager`, когда заполнены ВСЕ обязательные поля». Обязательные поля фактически служат условием срабатывания.
- Поэтому обязательным делай только то, что агент точно успеет собрать. Если «Имя» обязательное, а клиент уходит без имени, заявка не уйдёт. Обязательным остаётся один телефон; имя и остальное необязательные.
- В WhatsApp номер собеседника платформа знает сама, но поле всё равно должно быть в шаблоне и в сборе.
- Поля, которые собирает агент, и поля шаблона должны совпадать: в промпте описано, что и когда спрашивать, как называется поле.

## Когда отправлять заявку (политика)

Спроси клиента, какие данные минимум нужны менеджеру. Дальше по методологии:
- **По умолчанию:** заявка уходит, когда есть КОНТАКТ (телефон) и НАМЕРЕНИЕ (спросил цену, «хочу», «как купить», назвал даты или объём). Недостающее агент добирает одним сообщением и обновляет поля.
- **По желанию клиента:** только после резюме и «да» от человека (доставка еды, анкеты). Минус: заявка позже на 3–7 реплик, часть людей не дойдёт. Скажи клиенту цену этого решения.
- Всегда: один вызов на заявку; повтор «спасибо» после вызова не создаёт вторую карточку; нельзя говорить клиенту «передала специалистам», пока разговор продолжается.

## Передача человеку без заявки

`escalate_to_manager` (позвать человека) есть у любого агента. В промпте для неё: когда звать и одна фраза клиенту. «Уточню у команды» без вызова — брак: после фразы всегда вызов.

## Проверка

1. `fields show` — поля на месте, «Телефон» обязательный.
2. `notify status` — группа подтверждена.
3. Тест-чат: сценарий «контакт + намерение», сценарий «намерение без контакта», сценарий «спасибо после заявки». Карточка должна прийти в группу один раз.
