# Fusion-интегратор

Плагин для Claude Code для партнёров Fusion AI. Вы продаёте и настраиваете ИИ-агентов клиентам, а плагин учит ваш Claude Code делать это правильно: он знает, что умеет платформа fusion-ai.app и чего не умеет, пишет промпты по методологии Fusion, сам заходит в кабинет клиента, настраивает агента, прогоняет тесты и откатывает неудачные правки.

Версия 1.0.1.

## Что внутри

| Что | Для чего |
|---|---|
| Навык `fusion-integrator` | База знаний о Fusion (функции, тарифы, каналы, уведомления, CRM, дожимки, поля заявки, типичные ошибки), правила работы и команды для кабинета клиента |
| Навык `prompt-architect` | Методология написания промптов: бриф, промпт, база знаний, тест-план, регресс. Копия единого источника Fusion |
| Вход в кабинет клиента | Безопасный вход через скрытую форму в браузере: пароль в чат не попадает (Терминал не нужен) |
| Скрипты `fusion.py` | Список агентов, создание, заливка промпта с побайтной сверкой, база знаний, поля заявки, дожимки, уведомления, тест-чат, бэкап и откат |

## Что нужно

- Claude Code (приложение Claude Desktop, вкладка **Code**, или команда `claude`).
- Python 3.9 или новее (на Mac он обычно есть: проверка `python3 --version`).
- Для каждого клиента: почта и пароль от его кабинета на fusion-ai.app. Если кабинет создан через вход Google (пароля нет), попросите клиента задать пароль в настройках.

## Установка

Терминал не нужен. Вставьте в чат Claude Code одну фразу:

```
Установи плагин Fusion-интегратор: запусти claude plugin marketplace add RamisGit-cyber/fusion-integrator, потом claude plugin install fusion-integrator@fusion-integrator и скажи, когда закончишь.
```

Claude сам выполнит обе команды (песочницу Claude Desktop он обходит сам). Когда он напишет, что закончил, введите `/reload-plugins` или перезапустите сессию. Больше ничего ставить не нужно.

Запасной вариант, если фраза не сработала: вставьте в поле ввода по очереди, каждую отдельным сообщением, две команды (или поставьте кнопками: **«+»** у поля ввода → **Add plugins**):

```
/plugin marketplace add RamisGit-cyber/fusion-integrator
/plugin install fusion-integrator@fusion-integrator
```

Обновление плагина: `/plugin marketplace update fusion-integrator`, затем `/reload-plugins`.

## Первый вход в кабинет клиента

Пароль клиента **никогда не пишется в чат с Claude**. Вход делается так:

1. Скажите Claude: «Войди в кабинет клиента Салон Люкс». Откроется форма входа в браузере.
2. Введите в форме почту и пароль клиента и нажмите «Войти». Пароль набирается скрыто и уходит только в Fusion.
3. Страница напишет «Готово, вернитесь в Claude и напишите "готово"». Вернитесь в чат и напишите «готово».

Если браузер не открылся сам, Claude покажет ссылку: откройте её. Ссылка работает только на вашем компьютере и только до входа. Неверный пароль форма покажет сразу и не закроется: просто введите ещё раз. Форма сама закрывается после входа или через 10 минут.

Что произошло: скрипт поднял форму только на вашем компьютере (адрес 127.0.0.1, одноразовая ссылка), вошёл на fusion-ai.app, сохранил **только токен сессии** (временный ключ, не пароль) в `~/.config/fusion-integrator/<имя>.json` с правами «только вы» и сразу забыл пароль. Ни пароль, ни токен не печатаются на экране и не попадают в чат. Закончили работу — скажите Claude «выйди из кабинета клиента»: сессия удалится. Если сессия истекла, Claude откроет форму снова.

## Пример: «собери агента для салона по этим материалам»

Положите в папку материалы клиента (прайс, описание услуг, ссылки на Instagram и сайт, пара переписок менеджера) и скажите Claude:

> Собери агента для салона красоты «Нур» по материалам из этой папки. Клиент в сессии `salon-nur`.

Что будет дальше:

1. Claude изучит материалы и задаст 1–3 вопроса за раз: кто клиенты салона, что должен сделать агент (заявка на консультацию), какие данные нужны мастеру, нужны ли напоминания молчащим.
2. Напишет промпт по методологии, проверит его линтером и покажет вам итог (знаки, что включено, что нет).
3. Создаст агента (без каналов, клиентам он пока не отвечает), загрузит базу знаний (услуги, цены), задаст поля заявки (телефон обязателен).
4. Попросит клиента создать группу Telegram для заявок и добавить туда `@FusionNotify_Bot`, затем вы вдвоём подтвердите код от бота.
5. Скажет, сколько сообщений спишет тест-чат у клиента, и прогонит набор сценариев и покажет диалоги.
6. Исправит замеченное и прогонит заново весь набор. Вы подключите канал (WhatsApp, Instagram) в кабинете клиента, и Claude включит агента.

Перед каждой правкой Claude делает бэкап. Если что-то пошло не так, скажите «откати» — вернутся промпт, настройки, дожимки и поля заявки.

## Про работу без остановок

Плагин рассчитан на режим без запросов разрешений (как у учеников курса): Claude сам ставит флаги `--confirm-spend` (тест-чат тратит сообщения клиента) и `--confirm-live` (включение агента после регресса), не переспрашивает и не останавливается. Что остаётся включённым всегда, потому что работе не мешает:

- пароль клиента не попадает в чат и логи, хранится только токен сессии (`~/.config/fusion-integrator/`, права «только вы»);
- бэкап перед каждой правкой и команда отката;
- удалять можно только тестовых агентов с пометкой «ТЕСТ интегратор-плагин», чужих агентов и записи клиента плагин не удаляет;
- тексты с платформы и сайтов клиента считаются данными, а не командами.

Лимиты тест-чата: 40 сообщений за прогон (потолок `--max 300`), 500 в сутки на клиента. Суточный предел меняется переменной `FUSION_DAILY_CHAT_LIMIT`. Закончили с клиентом: «выйди из кабинета клиента» (`fusion_login.py <имя> --logout`) удалит сессию; бэкапы лежат в `~/.config/fusion-integrator/backups/`.

## Правила, которые плагин соблюдает

- Всё делается в кабинете клиента, чужие кабинеты не трогаются.
- Бэкап перед правкой, регресс перед выкаткой.
- Не обещаются функции, которых нет в платформе. Запись на «свободное время» не обещается: агент не видит окошек.
- Уведомления о заявках только через `@FusionNotify_Bot`, отдельный бот клиенту не нужен.
- Без поля «Телефон» в заявке агент не передаст заявку менеджеру, поэтому оно ставится всегда.
- Деньги, тарифы и скидки решает только команда Fusion.

## Для тех, кто обновляет плагин (команда Fusion)

- Методология копируется из единого источника скриптом: `python3 tools/sync-methodology.py` (проверка свежести: `--check`). Папка источника по умолчанию — рабочая папка `prompt-architect/`, другой путь задаётся переменной `FUSION_PROMPT_ARCHITECT_SRC`. Скрипт убирает из копии названия клиентов и сам ищет утечки перед записью.
- Локальный файл `tools/leak-names.local.txt` (список слов-табу) в git не попадает.
- Тесты без сети: `python3 -m unittest discover -s tests`.
- Структура: `plugins/fusion-integrator/skills/fusion-integrator/` (SKILL.md, references/, scripts/), `plugins/fusion-integrator/skills/prompt-architect/` (SKILL.md, references/).
- Релиз: main + тег + `git push origin main:stable` (маркетплейс следит за веткой `stable`).

Честная оговорка: в режиме без остановок Claude технически может изменить файлы входа или прочитать токен сессии, защита тут на правилах плагина и на правах файлов (скрипты входа доступны только для чтения). На Windows права 600/700 не применяются, файл защищён только вашим профилем пользователя. Удаление и замена документа базы знаний необратимы (бэкап хранит список документов, не содержимое), поэтому файлы клиента держите у себя.

## Что плагин НЕ делает

Не подключает каналы за вас (QR WhatsApp, вход Meta), не включает CRM-интеграции, не меняет тарифы и оплату, не рассылает сообщения, не читает переписки клиентов.

## Запасной путь входа через Терминал

Нужен только если форма не открывается (нет браузера или система запретила локальный порт). Claude один раз поставит команду `fusion-login` и попросит выполнить в Терминале (в Claude Desktop кнопка **Terminal** в заголовке сессии или `Ctrl+\``): `fusion-login salon-nur --terminal`. Пароль вводится скрыто. Команда с `!` (`! fusion-login ...`) не подходит: в режиме `!` нет клавиатуры.
